# Projetos com Presença

Landing page de Ian Akiles para reunir projetos digitais em uma interface moderna e responsiva.

## Visual e recursos

- Título com neon estático e animação leve de entrada e saída (opacidade e deslocamento).
- Fundo Matrix estático em SVG com 7% de opacidade, otimizado para reduzir processamento.
- Cards com imagens ilustrativas geradas por IA e links para os projetos.
- Botão de acesso ao portfólio: https://ianakiles.com.br/
- Suporte à preferência por movimento reduzido.

## Projetos

Garimpo Tech, StudyFlow, RECALL, Trilha de Sistemas, página de orçamento e RetroStudio.

## Estrutura

```text
index.html    # Página, estilos e animações
assets/       # Imagens e fonte local
README.md     # Orientações de publicação e licença da fonte
```

## Como usar

Abra `index.html` no navegador. Não é necessário instalar dependências ou compilar. As fontes do Google Fonts precisam de conexão com a internet.

Para publicar no GitHub Pages, envie `index.html` e a pasta `assets` para o repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**.
